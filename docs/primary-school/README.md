## 🏷️ 版本说明与教材选用

- **统编三科**：小学语文、道德与法治自2019年秋季起已实现全国统一使用教育部统编教材。
- **数学与英语**：各地根据省级教育厅用书目录选用，以人教版、北师大版、外研社版为最广泛应用版本。
- **2024秋季新教材**：2024年秋季学期起，全国小学一年级已启用依据《义务教育课程方案和课程标准(2022年版)》新修订的教材。

## 🏷️ 新高考与新教材结构说明

新高考背景下，高中课程结构分为：
- **必修课程**：全体高中学生必须修习的共同基础内容，作为学业水平合格性考试范围；
- **选择性必修课程**：学生根据高考选科与高校专业录取要求选择修习的内容，作为学业水平等级性考试范围；
- **选修课程**：由学校根据学生兴趣和发展需求自主开设的个性化拓展课程。

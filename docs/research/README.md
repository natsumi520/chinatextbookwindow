教材是国家意志、文化传承与学科育人的核心载体。教材研究中心聚焦我国建国以来、特别是新一轮课程改革以来的教科书编写思想、结构体系演变及主流版本比较。

---

## 📜 历次课程标准与教材改革演进

我国基础教育教科书建设历经数次重大变革，形成了目前以“统编三科”为核心、多版本百花齐放的格局：

| 改革阶段 | 标志性文件 | 教材编写核心特征 | 代表性教材版本 |
| :--- | :--- | :--- | :--- |
| **第八次基础教育课改 (2001~2011)** | 《基础教育课程改革纲要(试行)》 | “一纲多本”，打破单一统编，注重探究学习与生活经验衔接。 | 人教课标版、北师大版、苏教版、华东师大版等 |
| **课标深化修订期 (2011~2016)** | 2011版义务教育各学科课程标准 | 增强德育导向，优化知识容量与难度，注重学科思想方法。 | 2012/2013年修订版课标教材 |
| **国家统编三科时代 (2017~2021)** | 中办国办《关于加强和改进中小学教材建设的意见》 | 德育、历史、语文全国统一使用教育部统编教材，立德树人。 | 教育部统编三科中小学教材、普通高中统编教材 |
| **新时代核心素养期 (2022至今)** | 《义务教育课程方案和课程标准(2022年版)》 | 强化核心素养、跨学科主题学习（不低于10%课时）、学业质量标准。 | 2024年秋季起陆续启用的新修订教材 |

## 📚 教研重点与学术指引

::: tip 💡 核心素养导向下的教材使用建议
1. **注重真实情境设计**：教材各单元往往以主题任务群或项目式情境展开，教研中应挖掘课本中插图、思考题与探究活动的育人价值；
2. **注重学科育人与文化自信**：充分利用教材中的传统文化经典文本、中国现代科技成就与革命传统篇目；
3. **跨学科关联探索**：根据2022新课标要求，各学科教材均融入了综合实践与跨学科微项目，建议备课组跨学科联合教研。
:::
